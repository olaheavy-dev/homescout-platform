# 0007: Free and paid split

**ID:** PD-07  
**Status:** Accepted  
**Date:** 2026-10-23  
**Stage:** 1

## Context
The prototype shows which features would be free or paid, so the principle is needed now. Prices are not.

## Options
- **Free basics, paid extras:** Free: check a home, all public facts, calculators, compare 2 homes, own notes and questions. Paid: things that cost money to run (AI document checks, travel times, change alerts, shared editing, snapshots).
- **Limit by number:** Everything available, but only a few homes free.
- **Paid only, with a sample:** One free example, then pay. Risks hiding safety facts.

## Recommendation
Free basics, paid extras.

## Decision
Free basics, paid extras, as drafted in doc 02 §8. Limits, durations and prices stay open until the user study.

## Consequences
Public-interest facts are never paid-only. In the prototype, paid features show a labelled simulated boundary; no real payments.
