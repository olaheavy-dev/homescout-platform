# 0008: Name shown on the public demo

**ID:** PD-08  
**Status:** Parked (resume before the public demo)  
**Date:** 2026-10-23  
**Stage:** 1

## Context
'HomeScout' is already used by two property services (a London rental-alerts service and an Irish renting app). The demo is public, so its name is a public use. 'HomeVerifyCopilot' was considered and rejected: 'verify' promises something the product deliberately never claims, and 'Copilot' would make it sound like a Microsoft feature.

## Options
- **Brainstorm more first:** Get 8–10 candidates with clash checks, then shortlist.
- **Threshold / Keyhole:** Two early ideas; quick web search found no UK property app using them.
- **Keep HomeScout for now:** Decide just before the demo goes public.

### Quick web checks so far (not legal clearance)
| Name | Result |
|---|---|
| Beforehand, Lookround, Doorway | No clash found |
| Threshold | Used by an Irish renters' charity and a Barnet housing advice centre |
| Keyhole | A Copenhagen real-estate company uses it ([Nordic9](https://nordic9.com/companies/keyhole-company3671023035/)); keyhole.co is an analytics firm |
| Peephole | No property app found; "Peeple" is a US smart-peephole security product ([Wikipedia](https://en.wikipedia.org/wiki/Peeple_(company))) |
| HomeSpy | An existing iPhone HomeKit diagnostic app ([iCulture](https://www.iculture.nl/nieuws/homespy-app)); "spy" is also associated with phone-monitoring apps |
| HomeDiligence | No company found; "due diligence" is jargon renters may not relate to, and "Property Due Diligence" is an existing competitor |
| Settle, Doorstep, Homewise | UK property businesses already use them |
| Firstlook, Walkthrough, Porchlight, Plainsight | Used by property or tech businesses elsewhere |
| Plumbline, Hearthwise, Homeknown, Lookbefore, Sightline | No property clash found (Plumbline: two UK building contractors in a different trade) |
| Lintel | Sounds identical to Lintil, an Irish home-buying platform |
| Unlatch | French property-software company operating in the UK |
| HomeExplorer | No app found; descriptive, so hard to protect as a trade mark and hard to find in search |
| HomeSurvey | Avoid: "RICS Home Survey" is the professional surveying product, many surveying firms use the name, and it implies the app replaces a surveyor |
| PeepHole | Only an unlaunched concept app found; "peep" suggests snooping and is linked to an adult-content trade mark |

## Recommendation
Brainstorm more first.

## Decision
**Parked (23 October 2026).** Strongest candidates so far: Plumbline, Lookbefore, Homeknown. Resume with formal checks before the public demo. 'HomeScout' stays the private code name. The chosen name must pass trade mark, company and domain checks before the demo launches, and is set in one place in the code.

## Consequences
Nothing in stages 2–4 is blocked. Must be decided before stage 5's public launch.
