# 0005: Visual direction

**ID:** PD-05  
**Status:** Accepted  
**Date:** 2026-10-23  
**Stage:** 1

## Context
Design work in stage 4 needs a fixed starting style.

## Options
- **Warm and calm:** Editorial home photos on public pages; a clean, quiet workspace in forest green and warm off-white, starting from image 8 with less clutter.
- **Data dashboard:** Dense charts and maps. Overwhelming for first-time users.
- **Friendly assistant:** Chat-character led. Hides the evidence.

## Recommendation
Warm and calm.

## Decision
Warm and calm, using the tokens in doc 03 §6.

## Consequences
Stage 4 design starts from doc 03 §6 and the image 8 shell. Dashboard-style density is used only where the user asks for detail.
